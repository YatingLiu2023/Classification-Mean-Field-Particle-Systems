# Reproducing the paper

All paper configurations are stored in [`configs/`](../configs/). Unless stated otherwise, the reported Monte Carlo experiments use 50 independent repetitions.

| Paper item                   | Experiment                                  | Command                                                                                                                    |

## Smoke tests 

Before running the full experiments, the main pipelines can be checked using :

```bash
bash scripts/run_all_smoke.sh
```

## Run all paper experiments

All paper configurations can be launched sequentially with:

```bash
bash scripts/run_all_paper.sh
```

## Paper configurations

The configurations used for the reported experiments are:

```text
configs/main_paper.json
configs/scenario_b_paper.json
configs/D_selection_paper.json
configs/nn_scenario_a_paper.json
configs/nn_scenario_b_paper.json
```

The main plug-in configurations use:

* 50 Monte Carlo repetitions;
* training sizes N=100 and N=1000 particles per class;
* observation grids with 10 and 100 observation steps;
* 1000 test particles per class;
* independent auxiliary systems for drift-error evaluation.

Scenario A considers the two separation regimes specified in `main_paper.json`.

Scenario B uses the five class parameters

```text
(-6, -3, 0, 3, 6).
```

The reported numerical experiments use the untruncated estimator:

```text
clip_estimator = false
```

## Selection of the spline dimension

The `D`-selection experiment compares candidate spline dimensions using two validation schemes:

1. validation with held-out particles from the same interacting system;
2. validation with particles from an independent interacting system.

The candidate set and train/validation split are specified in:

```text
configs/D_selection_paper.json
```

The final test systems do not participate in the selection of D.

## Neural-network baseline

The released neural baseline follows the protocol used for the numerical comparison in the manuscript.

For each repetition, independent interacting particle systems are generated for:

1. training;
2. validation;
3. final testing.

Hyperparameters are selected using validation accuracy only. The selected configuration is then reinitialized and fully trained once before evaluation on the final test system. The repetition-level outputs record also:

* validation accuracy and loss;
* selected architecture and learning rate;
* number of predicted classes;
* per-class recalls;
* confusion matrix;
* class-collapse indicators;
* chance-or-worse indicators (indicators of whether the test accuracy is at or below the random-guessing level, i.e. 50\% for Scenario A and 20\% for Scenario B.).

## Generated outputs

A standard plug-in experiment produces:

```text
config.json
repetition_results.csv
summary.csv
manifest.json
```

The `D`-selection experiment additionally produces files containing:

* raw validation errors;
* per-repetition selected dimensions;
* selection frequencies;
* one-standard-error recommendations.

The execution manifest records information about the run, including the configuration and software environment.
